Travel Destination Explorer | Power BI

## Project Overview

This Power BI project explores travel destinations and helps users compare options according to their preferences and estimated travel costs. 
The interactive report brings together destination information, travel seasons, climate, travel type, ratings, and cost components to support more informed travel planning.

## Project Objectives

Explore destinations by country, climate, and primary travel type.

Narrow down options using a travel budget and preferred travel months.

Compare estimated travel costs and destination scores.

View destinations geographically and explore their characteristics.

Identify destinations worth investigating further.

## Tools and Skills

Power BI Desktop: Interactive dashboards, maps, charts, tables, cards, and slicers.

DAX: Custom calculations for estimated costs, average scores, and available destinations.

Data Modelling: Organising destination information with supporting budget, preference, and month-selection tables.

Data Visualisation: Comparing destinations and presenting travel information clearly.

Dashboard Features

## Destination Overview

A comparison table displays destinations and countries alongside estimated cost, average score, and recommended travel season.

## Interactive Travel Filters

Users can explore destinations using climate, travel type, budget, and preferred travel months.

## Destination Map

An interactive geographic map helps users explore travel destinations and their estimated costs.

## Travel Cost Analysis

Charts compare estimated flight costs, average hotel prices per night, daily food expenses, and daily activity costs across destinations.

## Destination Summary

A summary card displays the number of available destinations, while a treemap provides an additional view of destination comparisons.

## How to Use

Download the Power BI file from this repository.

Open it in Microsoft Power BI Desktop.

Select your preferred climate, travel type, budget, and travel months.

Explore the destination table, map, and cost comparison charts.

Compare the available options to identify suitable destinations.

## Limitations

Travel costs and ratings are based on the dataset used in this project and do not represent live booking prices. 
Actual costs may vary according to travel dates, trip duration, availability, and personal preferences.

## Conclusion

This project demonstrates how Power BI and DAX can be used to develop an interactive travel analysis dashboard. 
By combining destination characteristics, estimated costs, travel preferences, and ratings, the report provides a practical tool for comparing destinations and supporting travel-planning decisions.
